# Paradise Nursery

An online plant shop built with React and Redux Toolkit. Users can browse houseplants by category, add them to a shopping cart, adjust quantities, remove items, and see the total cost update dynamically.

## Features
- Landing page with a "Get Started" button
- Product listing grouped by category
- Shopping cart with quantity controls and total cost
- Navbar with live cart count

## Tech Stack
React, Redux Toolkit, Vite
